MAI（Microsoft AI）は、Microsoft が自社で開発する基盤モデル群です。Azure の Microsoft Foundry（旧 Azure AI Foundry）でホスト・課金され、Azure-first で配布されます。OpenAI モデル（Azure OpenAI 経由）とは別に、Microsoft 自身が開発・提供する基盤モデルファミリーとして位置づけられます。具体的な価格は下記の料金表の通りで、エンタープライズ向けのコスト・ライセンス・データ主権の選択肢を広げることが狙いです。

最新モデル（2026年9月）

microsoft.ai 公式ブログで確認できる最も新しい2系統。どちらも Microsoft Foundry / MAI Playground で試せます。

🖼️ MAI-Image-2.6 / MAI-Image-2.6-Flash（画像生成）— 2026-09-04

MAI の最強画像モデル。マルチ参照画像編集（複数画像から人物・商品・スタイル・シーンを合成）、Web グラウンディング、動的アスペクト比、最大 1.5K 解像度に対応。MAI-Image-2.6 は最高精度・画質、MAI-Image-2.6-Flash は同水準の品質を低遅延・高スループットで提供する位置づけ。Microsoft 公式発表（2026-09-04時点）では Arena で text-to-image・画像編集とも No.2、Artificial Analysis で画像編集 No.1。2.6-Flash は GPT-Image-2-Medium 比で 2.8倍高速・72%高効率 とされています。料金は公式ブログに テキスト入力 $5 / 画像入力 $8 / 画像出力 $38（2.6-Flash は $1.75 / $2.50 / $19、いずれも starts at）と記載されています。両方とも Public Preview で提供中。

🎙️ MAI-Transcribe-2（音声認識）— 2026-09-03

Microsoft のブログタイトルでは「世界で最も速く・正確で・安い音声認識モデル」と位置づけ。価格は $0.10 / 時間（年末までの限定オファー）。FLEURS 60言語で No.1（平均 WER 5.2%）、Artificial Analysis AA-WER で No.2（2.0%）。人工分析ベースの速度で GPT-Transcribe の10倍・Scribe v2 の7倍・Gemini 3.5 Transcribe の5倍。話者分離・単語タイムスタンプ・キーワードバイアス・verbatim/clean の文字起こしスタイル・コードスイッチングなどに対応。

出典: Pushing the quality-cost frontier with MAI-Image-2.6（2026-09-04） · MAI-Transcribe-2（2026-09-03）

使い方（API / アクセス方法）

MAI は主に Azure AI Foundry / Microsoft Foundry 経由でモデルをデプロイして呼び出します。一部は MAI Playground や OpenRouter でも試せます。

  • Microsoft Foundry（ai.azure.com/catalog/models）: カタログから MAI モデルを選び、model ID を指定してデプロイ。認証は Azure（Azure OpenAI と同様の API キー / Entra ID）。
  • MAI Playground（playground.microsoft.ai）: API キー無しでブラウザから試せる。例: playground.microsoft.ai/chat?model=mai-image-2-6-flash / ?model=mai-transcribe-2。
  • MAI-Transcribe-2（音声認識）: 公式は Azure Speech の MAI-Transcribe ドキュメント（REST / SDK）。OpenRouter ではモデルID microsoft/mai-transcribe-2。
  • 画像生成（MAI-Image-2.x）: Foundry の画像生成モデルとして text-to-image / image-editing をデプロイ。マルチ参照編集・Web グラウンディングは MAI-Image-2.6 系が対応。
  • 推論（MAI-Thinking-1）: 推論モデル。キャッシュ入力が0.20と安いのが特徴。

⚠️ 正確なリクエスト形式・パラメータはモデルごとに異なり、かつ変更され得るため、必ず公式ドキュメント（Learn / Foundry の各モデルページ）を参照してください。本ページでは具体的な API リクエストのボディまでは記載しません（一次情報での裏取りができていないため）。

押さえておきたいポイント

  • Microsoft の自社開発モデルであり、OpenAI モデル（Azure OpenAI 経由）とは別系統。データ主権・ライセンスの選択肢を広げるものとして、企業向けに提案されています。
  • Azure-first: 他社（Google・Meta・Mistral・DeepSeek 等）のオープンモデルと並んで Foundry カタログ（11,000+モデル）に搭載され、統一された Azure 課金・運用の一部として使えます。
  • 価格の例: 推論モデル MAI-Thinking-1 は $2/$8（キャッシュ $0.20）、画像生成は MAI-Image-2.5 Flash が $1.75/$19.50。最新の MAI-Image-2.6 はテキスト入力 $5・画像入力 $8・画像出力 $38、2.6-Flash は $1.75 / $2.50 / $19（いずれも starts at・public preview、公式ブログ記載）。
  • モダリティの広がり: 音声認識（Transcribe）・音声生成（Voice）・画像生成（Image）・画像理解（VLM 系）・コード（Code）・推論（Thinking）と、LLM以外の周辺分野までカバー。
