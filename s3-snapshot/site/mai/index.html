Microsoft AI (MAI) シリーズ

OpenAI への依存を再調整するため、Microsoft が自社で開発した基盤モデル群。2026年に本格展開し、推論・コーディング・画像生成・音声認識・Voice をカバー。

MAI（Microsoft AI）は、Microsoft が自社で開発する基盤モデル群です。Azure の Microsoft Foundry（旧 Azure AI Foundry）でホスト・課金され、Azure-first で配布されます。OpenAI モデル（Azure OpenAI 経由）とは別に、Microsoft 自身が開発・提供する基盤モデルファミリーとして位置づけられます。具体的な価格は下記の料金表の通りで、エンタープライズ向けのコスト・ライセンス・データ主権の選択肢を広げることが狙いです。

最新モデル（2026年10月）

microsoft.ai 公式ブログで確認できる直近の発表（2026-10-02分を含む）。いずれも Microsoft Foundry / MAI Playground などで試せます。

🎧 MAI-Transcribe-2-Streaming（ストリーミング音声認識）— 2026-10-02

MAI 初のストリーミング音声認識モデル。話し終わりを待たずに、音声を受け取ってから約100msで partial（話している途中に出てくる暫定の文字起こし）を返します。60言語に対応し、言語の自動・継続的な検出も可能。入手経路は Microsoft Foundry / MAI Playground / OpenRouter / Vercel / Azure Voice Live（LiveKit も「coming soon」）。同じ発表で音声生成の MAI-Voice-2.1 / 2.1-Flash（23言語・26ロケール）も出ています。価格は下の「参考価格」の表にまとめました。なお「確認済み料金表」とは、Azure の公式料金ページに実際に載っているかを当サイトで確認した表のことです（2026-10-17 時点で、本モデルと MAI-Voice-2.1 系はこの表に載っていません）。

公式ブログの逐語: "MAI-Transcribe-2-Streaming delivers low-latency, real-time transcripts in 60 languages, all while supporting automatic, continuous language detection." / "Rather than waiting for someone to finish speaking before returning text, it produces its first hypotheses (known as "partials") in just over 100ms of receiving audio." / "MAI-Transcribe-2-Streaming is available at an introductory price of $0.54 per hour of audio through the end of the year."

🖼️ MAI-Image-2.6 / MAI-Image-2.6-Flash（画像生成）— 2026-09-04

MAI の最強画像モデル。マルチ参照画像編集（複数画像から人物・商品・スタイル・シーンを合成）、Web グラウンディング、動的アスペクト比、最大 1.5K 解像度に対応。MAI-Image-2.6 は最高精度・画質、MAI-Image-2.6-Flash は同水準の品質を低遅延・高スループットで提供する位置づけ。Microsoft 公式発表（2026-09-04時点）では Arena で text-to-image・画像編集とも No.2、Artificial Analysis で画像編集 No.1。2.6-Flash は GPT-Image-2-Medium 比で 2.8倍高速・72%高効率 とされています。料金は公式ブログに テキスト入力 $5 / 画像入力 $8 / 画像出力 $38（2.6-Flash は $1.75 / $2.50 / $19、いずれも starts at）と記載されています。両方とも Public Preview で提供中。

🎙️ MAI-Transcribe-2（音声認識）— 2026-09-03

Microsoft のブログタイトルでは「世界で最も速く・正確で・安い音声認識モデル」と位置づけ。価格は $0.10 / 時間（年末までの限定オファー）。FLEURS 60言語で No.1（平均 WER 5.2%）、Artificial Analysis AA-WER で No.2（2.0%）。人工分析ベースの速度で GPT-Transcribe の10倍・Scribe v2 の7倍・Gemini 3.5 Transcribe の5倍。話者分離・単語タイムスタンプ・キーワードバイアス・verbatim/clean の文字起こしスタイル・コードスイッチングなどに対応。

出典: Pushing the quality-cost frontier with MAI-Image-2.6（2026-09-04） · MAI-Transcribe-2（2026-09-03） · Our first streaming transcription model（2026-10-02）

料金表の読み方（画像生成と画像理解の違い）: Azure Foundry Models pricing の Microsoft セクションでは、モデルごとに「入力」欄の種類が違います。MAI-Image-2.5 / 2.5 Flash / 2.5 Pro は入力が Text / Image の2種類に分けて掲載され、画像を入力として渡す使い方の単価が別建てです。一方 MAI-Image-2 / MAI-Image-2-Efficient は入力がテキスト1種類のみで、MAI-Thinking-1 などのテキスト系も入力欄はテキストのみの掲載です。つまり入力欄が「Text / Image」に分かれているモデル＝画像を入力（理解）に使えるモデル、出力欄が画像のモデル＝画像を生成するモデル、と読み分けられます。（2026-10-17 に公式料金ページで再確認）

使い方（API / アクセス方法）

MAI は主に Azure AI Foundry / Microsoft Foundry 経由でモデルをデプロイして呼び出します。一部は MAI Playground や OpenRouter でも試せます。

  • Microsoft Foundry（ai.azure.com/catalog/models）: カタログから MAI モデルを選び、model ID を指定してデプロイ。認証は Azure（Azure OpenAI と同様の API キー / Entra ID）。
  • MAI Playground（playground.microsoft.ai）: API キー無しでブラウザから試せる。例: playground.microsoft.ai/chat?model=mai-image-2-6-flash / ?model=mai-transcribe-2。
  • MAI-Transcribe-2（音声認識）: 公式は Azure Speech の MAI-Transcribe ドキュメント（REST / SDK）。OpenRouter ではモデルID microsoft/mai-transcribe-2。
  • MAI-Transcribe-2-Streaming（2026-10-02・ストリーミング）: 公式ブログでは入手経路を OpenRouter / Microsoft Foundry / MAI Playground / Vercel / Azure Voice Live としており、LiveKit は「coming soon」と記載されています。話し終わりを待てない用途（リアルタイムの会議文字起こしなど）向けです。
  • 画像生成（MAI-Image-2.x）: Foundry の画像生成モデルとして text-to-image / image-editing をデプロイ。マルチ参照編集・Web グラウンディングは MAI-Image-2.6 系が対応。
  • 推論（MAI-Thinking-1）: 推論モデル。キャッシュ入力が0.20と安いのが特徴。

⚠️ 正確なリクエスト形式・パラメータはモデルごとに異なり、かつ変更され得るため、必ず公式ドキュメント（Learn / Foundry の各モデルページ）を参照してください。本ページでは具体的な API リクエストのボディまでは記載しません（一次情報での裏取りができていないため）。

押さえておきたいポイント

  • Microsoft の自社開発モデルであり、OpenAI モデル（Azure OpenAI 経由）とは別系統。データ主権・ライセンスの選択肢を広げるものとして、企業向けに提案されています。
  • Azure-first: 他社（Google・Meta・Mistral・DeepSeek 等）のオープンモデルと並んで Foundry カタログ（11,000+モデル）に搭載され、統一された Azure 課金・運用の一部として使えます。
  • 価格の例: 推論モデル MAI-Thinking-1 は $2/$8（キャッシュ $0.20）、画像生成は MAI-Image-2.5 Flash が $1.75/$19.50。最新の MAI-Image-2.6 はテキスト入力 $5・画像入力 $8・画像出力 $38、2.6-Flash は $1.75 / $2.50 / $19（いずれも starts at・public preview、公式ブログ記載）。
  • 音声認識の最新形（2026-10-02）: MAI-Transcribe-2-Streaming は60言語のストリーミング文字起こしで、話し終わりを待たずに約100msで暫定結果を返す設計。年内の導入価格は $0.54/時（公式ブログ記載）。Azure の確認済み料金表にはまだ未掲載です。
  • ローカル（オンデバイス）展開（2026-10-07）— 必要メモリ・対応環境・導入手順: Microsoft の開発者ブログが MAI Code 1.1 Flash のローカル版を発表しました。MAI Code 1.1 Flash はコーディング特化の MoE で 総パラメータ137B・アクティブ6.8B、オンデバイス版は量子化と投機的デコーディングでサイズを 約53GB（Bfloat16 のクラウド版比80%減）に抑え、256k コンテキストでピークメモリ75.5GB（2026-10-05 テスト）。NVIDIA RTX Spark 搭載 Windows PC（Surface Laptop Ultra）の GitHub Copilot で最初に提供され、実行は Windows チームのオープンソース Microsoft Execution Containers（MXC）でサンドボックス化されます。GitHub Copilot CLI・Copilot アプリ・VS Code のいずれでも使え、Windows ML プロバイダから MAI Code 1.1 Flash を選ぶか、OpenAI 互換のローカルエンドポイントに接続するかの2通りの導入方法があります。この記事には料金の記載がなく、Azure の料金表にも MAI-Code-1.1 は未掲載（2026-10-13時点）のため、コスト比較には使えません。
  • モダリティの広がり: 音声認識（Transcribe）・音声生成（Voice）・画像生成（Image）・画像理解（VLM 系）・コード（Code）・推論（Thinking）と、LLM以外の周辺分野までカバー。
