結論（3行）

  • トークン課金のモデルで1枚あたりの換算値を公開しているのはGoogleだけ（Metaは固定の1枚単価を公開）。Nano Banana 2.1 は1K（1024×1024px）で$0.0336/枚、Nano Banana Pro は1K/2Kで$0.134/枚。一方Metaの Muse Image は$0.01/枚の固定で、公表単価の中では最も安い（品質は別問題）。
  • MicrosoftのMAI-Imageは出力トークン単価が$19〜$106/1Mと5倍以上ひらく。ただし1枚あたりのトークン数が公開されていないため、1枚単価は公式の計算機で試算するまで確定しません。
  • 動画は別表。Gemini Omni 1.2 Flash は720pで約$0.07/秒（10秒で約$0.70）が公式の換算値。OpenAIの料金ページに動画生成モデルの単価行は見当たらず、Googleの「Veo」名のモデルも現行料金ページには記載がないため未確認として扱います。

「$30/1Mトークン」と「$0.01/枚」をそのまま並べても、どちらが高いかは決まりません。1枚あたり何トークン消費するかが分かって初めて比較できます。
  • 画像は「出力トークン」課金が主流（Google・Microsoft・OpenAI）。トークン数は解像度と品質で変わるため、同じ「$30/1M」でも1枚単価は変わります。Googleは1K＝1,120トークン、4K＝3,780トークンと公表しています（Nano Banana 2.1）。
  • Metaだけが「1枚 $0.01」の固定単価。単価が読める代わりに、解像度や品質ごとの値段の差は表からは分かりません。
  • 動画は「出力トークン×秒数」。実質は秒課金なので、Googleは注記で秒あたり換算を出しています。
  • 入力側は別単価。参照画像を何度も入れる編集用途では入力が効きます（Nano Banana Pro は入力画像 560トークン＝$0.0011/枚）。

注意（4点）

  • MAI-Image-2.6 / 2.6-Flash の単価はブログにしか載っていません。Azureの「Foundry Models pricing」表は今回も MAI-Image-2 / 2-Efficient / 2.5 / 2.5 Flash / 2.5 Pro の5行で、2.6 は未反映でした。契約前に必ずFoundryの価格ページで再確認してください。
  • Googleの1枚単価は解像度で3倍以上変わります（Nano Banana 2.1：1K $0.0336 ↔ 4K $0.113）。「1枚$0.03」で見積もると、4K運用で請求が3倍になります。
  • GPT-Image-2.6 の1枚単価は公式の計算機で確認が必要。公開されているのは$30/1M画像出力トークンで、1枚あたりのトークン数の固定表があるのは gpt-image-2 より前のモデルです。
  • Batch（非同期）は概ね半額（Google $15/1M、OpenAI $15/1M）。速度要件が無い処理はBatch前提で見積もってください。
換算の前提と、公式の逐語（クリックで開く）
  • 1枚あたりの換算は各社公式の明記値を使っています（当サイトでトークン数を見積もった箇所はありません）。
  • MAI-Image-2.5系のAzure表記は「Output (Per 1M tokens)」で、画像出力とテキスト出力の内訳は分かれていません。
