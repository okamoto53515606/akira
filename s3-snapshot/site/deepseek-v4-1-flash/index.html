DeepSeek V4.1 Flash 実践ガイド

2026-09-10、DeepSeek は新アーキテクチャ世代の最小モデル DeepSeek-V4.1-Flash を正式リリースしました。 料金は V4 Pro より大幅に安く、ネイティブの画像入力（Vision）にも対応します。 このページでは、公式料金ページとChange Logだけで裏取りした料金・スペック・ベンチマークに加え、 VS Code GitHub Copilot Chat での導入手順と、V4 Pro との関係（2026-09-14 以降も提供継続と公式が告知）を整理します。 料金比較は 料金比較ページ、コスト試算は トークン計算機、リリース経緯は リリース年表も参照してください。

● 最終更新: 2026年9月15日  |  一次情報: 公式料金ページ・Change Log（2026-09-10）  |  取得日: 2026-09-15

3行でわかる要点

  • 現行の主力は V4.1 Flash。モデルID（APIリクエストで指定する文字列）は deepseek-flash（VS Code 側の表示・選択肢は拡張機能の更新により異なる場合があります）。コンテキスト1M・最大出力384K・ネイティブ画像入力対応。
  • 料金は V4 Pro より大幅に安い。入力（cache miss）オフピーク $0.15 / ピーク $0.30、出力 オフピーク $0.60 / ピーク $1.20（USD・1Mトークンあたり）。参考として V4 Pro は入力オフピーク $0.66 / 出力オフピーク $1.98 です。
  • V4 Pro は 2026-09-14 以降も提供が継続されます。公式は以前「9/14 以降 deepseek-v4-pro 宛を V4.1 Flash へルーティングする」と予告していましたが撤回しました。deepseek-v4-pro の書き換えは不要です（後述）。

V4 Pro との関係（2026-09-13 時点: 提供継続）

公式ドキュメントの記載に基づく事実のみを記載します。

✅ 公式は「V4 Pro の提供を継続する」と告知 — 9/14 のルーティング予告は撤回されました

  • 2026-09-10 の V4.1 Flash リリース告知では、V4 Pro を順次 retire し、2026-09-14 以降 deepseek-v4-pro 宛のリクエストを V4.1 Flash へルーティングするとされていました。
  • その後 DeepSeek はこの予告を撤回し、料金ページの注記(2) と Change Log を「2026-09-14 以降も V4 Pro の API サービス提供を継続し、課金方法は変更しない」に差し替えました（原文: "In response to user demand, we have decided to continue providing API services for DeepSeek V4 Pro after September 14, 2026, with the billing method remaining unchanged."）。
  • deepseek-v4-pro は現在も使い続けられます。コードや API キーの書き換えは不要です。V4 Pro 専用の料金表（オフピーク 入力 $0.66 / 出力 $1.98）も公式ページに現存し、V4.1 Flash の価格に統合されてはいません。
  • ただし公式は「変更があれば改めて告知する」としているため、将来の変更がゼロとは言い切れません。V4 Pro の詳細・経緯・使い分けは V4 Pro 提供継続のまとめに記載しています。

導入手順（VS Code GitHub Copilot Chat・3ステップ）

運営者（okamoちゃんねる）が V4 系で実際に行った手順です。拡張機能の名称・モデルピッカーの表示は更新される場合があるため、公式の手順も併せて確認してください。

STEP 1

APIキーを取得

platform.deepseek.com でアカウント登録。PayPal またはクレジットカード（VISA/Mastercard）でチャージし、sk- から始まるAPIキーを発行します。完全プリペイド方式で、最低チャージは $2 です。

STEP 2

拡張機能をインストール

VS Code Marketplace で DeepSeek V4 for Copilot Chat（発行元: Vizards）をインストールします。

STEP 3

設定して利用開始

コマンドパレット（Cmd/Ctrl+Shift+P）→ DeepSeek: Set API Key でキーを登録。Copilot Chat のモデルピッカーで DeepSeek V4 系を選ぶと会話を開始できます。

💡 モデル名をコードから直接指定する場合は deepseek-flash を使います。既存コードが deepseek-v4-pro を指している場合も、そのまま動き続けます（V4 Pro は 2026-09-14 以降も提供継続。詳細は上記）。

運営者の導入記録（2026-07-04・V4 Pro 時点のもの）: okamoちゃんねるの導入手順メモ

Azure AI Foundry で動かす（DeepSeek-V4-Flash-0731）

DeepSeek 自社 API だけでなく、Microsoft Azure の Azure AI Foundry（Microsoft Foundry） 経由でも DeepSeek 系モデルをデプロイできます。 ここでは Azure が「Direct from Azure」として販売している DeepSeek-V4-Flash-0731 を、Azure CLI でデプロイして curl で疎通確認するまでの手順を示します。

ℹ️ DeepSeek-V4-Flash-0731 と V4.1 Flash の関係: -0731 は V4.1 Flash のひとつ前の世代（2026-07-31 リリース・V4-Flash-Preview と同じアーキテクチャ／サイズで再事後学習したもの）です。 DeepSeek 自社 API では V4 Flash 系は退役して V4.1 Flash に統合されましたが、Azure AI Foundry では DeepSeek-V4-Flash-0731 が現在も Preview モデルとして提供されています（2026-09-13 時点）。 Azure 側の仕様は Microsoft Learn の記載に基づきます。コマンド列の流れは運営者（okamoちゃんねる）が 2026年9月時点で動作確認済みのものです。

前提

  • Azure サブスクリプション（リソースを作成できる権限があること。リソースプロバイダー登録には Owner 権限が必要です）
  • Azure CLI（az）。az cognitiveservices 系コマンドは core に同梱されているため、Azure CLI 2.60 以降であれば追加拡張は不要です
  • az login で対象サブスクリプションにログイン済みであること

使うプレースホルダ

コマンド内のプレースホルダ一覧
プレースホルダ意味・指定する値
<SUBSCRIPTION_ID_OR_NAME>使う Azure サブスクリプションの ID または名前
<RESOURCE_GROUP>リソースグループ名（例: rg-deepseek）
<LOCATION>リージョン（例: eastus）。モデルによって提供リージョンが異なるため、Azure ポータルのモデルカタログで確認してください
<ACCOUNT_NAME>Azure AI Services アカウント名。全世界で一意にする必要があります（例: dsflash0731）。--custom-domain にも同じ値を使います
<DEPLOYMENT_NAME>デプロイ名（任意）。API 呼び出しの model に指定するのはモデル名ではなく、このデプロイ名です（例: deepseek-0731）
<MODEL_VERSION>モデルのバージョン文字列。実値は次の az cognitiveservices account list-models で確認してください（本ページでは断定しません）
<API_KEY>Azure AI Services アカウントのキー（手順内で CLI から取得します）

STEP 0 — Azure CLI の準備とリソースプロバイダー登録

最初にこれを済ませておくと、後の手順で MissingSubscriptionRegistration エラーに当たりません。

# Azure CLI のバージョン確認（2.60 以降を推奨）
az version

# 未ログインならログイン
az login

# 使うサブスクリプションを選択
az account set --subscription "<SUBSCRIPTION_ID_OR_NAME>"

# リソースプロバイダーを登録（MissingSubscriptionRegistration 対策）
az provider register --namespace Microsoft.CognitiveServices

# 登録状態を確認（Succeeded になるまで数分かかることがあります）
az provider show --namespace Microsoft.CognitiveServices --query registrationState -o tsv

STEP 1 — リソースグループを作成

az group create \
  --name "<RESOURCE_GROUP>" \
  --location "<LOCATION>"

STEP 2 — Azure AI Services アカウントを作成

--custom-domain を指定すると、以降のエンドポイントが https://<ACCOUNT_NAME>.openai.azure.com/ の形式になります。

az cognitiveservices account create \
  --name "<ACCOUNT_NAME>" \
  --resource-group "<RESOURCE_GROUP>" \
  --kind AIServices \
  --sku S0 \
  --location "<LOCATION>" \
  --custom-domain "<ACCOUNT_NAME>" \
  --assign-identity \
  --allow-project-management true \
  --yes

STEP 3 — DeepSeek-V4-Flash-0731 をデプロイ

まず利用可能なモデルとバージョンを確認し、その値でデプロイします。

# デプロイ可能な DeepSeek 系モデルとバージョンを確認
az cognitiveservices account list-models \
  -n "<ACCOUNT_NAME>" -g "<RESOURCE_GROUP>" \
  --query "[?contains(name,'DeepSeek')].{name:name,format:format,version:version}" -o table

# モデルをデプロイ（SKU は GlobalStandard。--sku-capacity の値は下の注意書きを参照）
az cognitiveservices account deployment create \
  --name "<ACCOUNT_NAME>" \
  --resource-group "<RESOURCE_GROUP>" \
  --deployment-name "<DEPLOYMENT_NAME>" \
  --model-name "DeepSeek-V4-Flash-0731" \
  --model-version "<MODEL_VERSION>" \
  --model-format "DeepSeek" \
  --sku-name "GlobalStandard" \
  --sku-capacity 20

💡 --sku-capacity はクォータ（Tokens Per Minute、千トークン単位）として消費されます。容量が足りないと InsufficientQuota でデプロイに失敗することがあるため、その場合は値を調整するか、Azure ポータルでクォータの増加を申請してください。

⚠️ --sku-capacity の実運用（運営者実測・2026-09-15）

  • --sku-capacity 1 でもデプロイ自体は成功しますが、少なすぎて API を少し使っただけでクォータ不足のエラーになりました。運営者は 20 に引き上げてから安定して運用しています。
  • 確保する容量は az cognitiveservices usage list で確認できる limit（上限）の範囲内で指定してください。
  • 上限まで使い切らないでください。上限を使い切ると、同じサブスクリプションで他のデプロイにクォータを割り当てられなくなります。
# 現在のクォータ使用量と上限を確認（LOCATION はデプロイ先リージョン）
az cognitiveservices usage list --location "<LOCATION>" -o table

STEP 4 — 接続情報を環境変数に入れる

# エンドポイント（OpenAI 互換）と API キーを取得
export AZURE_AI_ENDPOINT="https://<ACCOUNT_NAME>.openai.azure.com/openai/v1/"
export AZURE_AI_API_KEY="$(az cognitiveservices account keys list \
  --name "<ACCOUNT_NAME>" \
  --resource-group "<RESOURCE_GROUP>" \
  --query key1 -o tsv)"

# API 呼び出しの model に入れるのはデプロイ名
export DEPLOYMENT_NAME="<DEPLOYMENT_NAME>"

STEP 5 — curl で疎通確認

curl -sS "$AZURE_AI_ENDPOINT/chat/completions" \
  -H "Content-Type: application/json" \
  -H "api-key: $AZURE_AI_API_KEY" \
  -X POST \
  -d '{
    "model": "'"$DEPLOYMENT_NAME"'",
    "messages": [
      { "role": "user", "content": "Reply with just OK." }
    ]
  }'

✅ 応答 JSON が返れば疎通完了です。model にデプロイ名を渡している点に注意してください（モデル名 DeepSeek-V4-Flash-0731 を渡すと 404 などになることがあります）。 環境変数にキーを置きたくない場合は -H "api-key: <API_KEY>" を直接指定します。 Entra ID（旧 Azure AD）で認証する場合は、公式チュートリアルにあるとおり DefaultAzureCredential 等でスコープ https://ai.azure.com/.default のトークンを取得する方式も使えます。

⚠️ MissingSubscriptionRegistration が出たら

次のようなエラーです（HTTP 409 / Conflict）。サブスクリプションで Microsoft.CognitiveServices リソースプロバイダーが未登録なだけなので、リソース作成側の問題ではありません。

MissingSubscriptionRegistration
The subscription is not registered to use namespace 'Microsoft.CognitiveServices'.
  • 対処1（CLI）: az provider register --namespace Microsoft.CognitiveServices を実行し、az provider show --namespace Microsoft.CognitiveServices --query registrationState -o tsv が Registered になるまで待ちます（数分かかることがあります）。
  • 対処2（ポータル）: Azure ポータル →「サブスクリプション」→「リソースプロバイダー」→ Microsoft.CognitiveServices を選び「登録」。
  • 権限: 登録にはサブスクリプションの Owner 権限が必要です。権限が無い場合は管理者に依頼してください。
  • 公式のトラブルシューティング: Register a resource provider
⚠️ Azure 側の料金は本ページに掲載していません。 Azure AI Foundry の DeepSeek 系モデルの単価は、DeepSeek 自社 API の peak/off-peak 単価とは別体系です。当サイトで一次情報（DeepSeek-V4-Flash-0731 に特定した確定値）を確認できていないため、 ご契約前に Azure の Foundry Models 料金ページまたは Azure ポータルで必ずご確認ください。

よくある質問

Q. DeepSeek V4.1 Flash の料金はいくらですか？

A. 1Mトークンあたり、入力（cache miss）がオフピーク $0.15・ピーク $0.30、入力（cache hit）がオフピーク $0.003・ピーク $0.006、出力がオフピーク $0.60・ピーク $1.20 です。ピークは平日の 01:00-04:00 UTC と 06:00-10:00 UTC（日本時間 10:00-13:00 / 15:00-19:00）で、土日は終日オフピーク。オフピークはピークの半額です。

Q. 9月14日以降に deepseek-v4-pro を使うとどうなりますか？

A. 引き続き使えます。DeepSeek は「ユーザーの要望を受け、2026-09-14 以降も V4 Pro の API サービス提供を継続し、課金方法は変更しない」と告知しました。以前の「9/14 以降は V4.1 Flash へルーティング」という予告は撤回済みです。コードや API キーの書き換えは不要です。

Q. DeepSeek V4.1 Pro はいつリリースされますか？

A. 2026-09-13 時点で公式にリリース時期は発表されていません。なお以前の注記には「将来 V4.1 Pro がリリースされるまで（until V4.1 Pro is released in the future）」という記述がありましたが、その注記自体が V4 Pro 提供継続の文面に差し替えられています。当サイトでも公式発表が出た時点で更新します。

Q. 画像を読めますか？

A. はい。V4.1 Flash は新アーキテクチャ世代でネイティブのマルチモーダル視覚理解に対応し、公式の機能表でも Vision が「✓」です（旧 V4 Pro は非対応）。画像を含むモデル横断の比較は マルチモーダル対応LLM一覧を参照してください。

Q. deepseek-v4-flash のままでも動きますか？

A. 一時的な互換のために受理されますが、対応する旧モデルは退役済みで、リクエストは V4.1 Flash が処理し V4.1 Flash の価格で課金されます。新規実装では deepseek-flash を指定してください。

Q. コンテキスト長と最大出力は？

A. コンテキスト長 1M トークン、最大出力 384K トークンです。thinking mode は non-thinking と thinking の両方に対応し、thinking が既定です。
