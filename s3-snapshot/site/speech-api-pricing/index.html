音声API料金比較 【2026年11月版】

このページの範囲: 音声まわりのAPIは、同じ「$」でも課金の単位が4種類に分かれています（1M文字・1Mトークン・1分・1時間）。ここでは読み上げ（TTS）と文字起こし（STT）を、「1分あたり」「1,000文字あたり」に換算して同じ土台に載せます。換算は当サイトの前提を明示し、公式が秒・分の換算を併記している場合はそれを逐語で引きます。料金以外（品質・レイテンシ）の優劣は各社の主張が割れるため、当サイトは数値を出しません。

●最終更新: 2026年11月15日 | 各社の公式ページを2026-11-15に取得。取れなかった項目は「未確認」と明記しています。

先に結論（数字が逆転する3点）

結局どれが安いか（1分＝300文字の前提で計算）

  • 音声生成（TTS）: MAI-Voice-2.1-Flash が $0.0045/分で最安（文字課金）。ただし価格は Microsoft の公式ブログ記載で、Azure の確認済み料金表には未掲載。同額の OpenAI tts-1 は Deprecated。
  • 文字起こし: MAI-Transcribe-2 が $0.10/時間で最安（年末までの期間限定）。通常価格帯は Meta Muse Voice Transcribe $0.18/時間、Gemini 3.5 Transcribe 約$0.18〜0.30/時間。
  • リアルタイム双方向: Gemini 3.8 Live 系 約$0.023/分（≒$1.38/時間）。OpenAI の gpt-realtime-2.1 は1分あたりの音声トークン換算が公式に無く、当サイトでは未確認。

いちばん間違えやすいところ: TTSの単価は「1M文字 $15」（OpenAI tts-1）と「1M音声トークン $9」（Gemini 3.8 Flash TTS）のように単位が違う形で公表されます。数字だけ見ると $9 のほうが安く見えますが、音声トークンは公式換算で1秒25トークン＝1分1,500トークンなので、1分あたりに直すと $0.0135。一方 $15/1M文字は1分300文字の前提で $0.0045 になり、数字が大きいほうが3分の1安いという逆転が起きます。単位をそろえずに「$9 対 $15」で比べると、選定を誤ります。なお、この例に使った OpenAI tts-1 は2026-11-15時点でモデルページに Deprecated 表記があります（下のTTS表を参照）。

上の「1分 = 300文字」は日本語ナレーション前提です。英語ナレーションは一般に速く（毎分約900文字）、1分の音声に載る文字数は日本語の約3倍になります。文字課金のモデルは1分あたりの費用が下の表の約3倍になる一方、1,000文字あたりの費用は変わりません。トークン課金のモデルは逆で、読み上げが速いほど1,000文字の音声は短くなるため両方の列が動きます。つまり本ページの「1分あたり」「1,000文字あたり」は日本語ナレーションでの目安で、ベンダー間で直接比べられるのは1M単位の公表単価です。

用途別の選び方

  • 大量の録音をとにかく安く文字起こし → MAI-Transcribe-2（$0.10/時間・期間限定）。定価前提なら Meta Muse Voice Transcribe か Gemini 3.5 Transcribe（どちらも$0.18/時間）。
  • 会議のライブ字幕 → 遅延とセットで選ぶ。MAI-Transcribe-2-Streaming（約100msで部分結果・$0.54/時間）／Gemini 3.5 Transcribe Live（$0.30〜$0.54/時間）／OpenAI gpt-live-transcribe（$1.02/時間）。
  • ナレーション・読み上げ → 文字課金で現行の最安は MAI-Voice-2.1-Flash（1,000文字 $0.015）。OpenAI の文字課金TTS 3モデルは Deprecated なので、新規は GPT-Live（$0.05/分・秒単位）か Gemini のトークン課金で見積もる。上限側は Gemini 3.1 Flash TTS Preview（1,000文字 $0.10）。
  • 音声対話エージェント → 単価表のTTS行ではなく入出力合計で見る（Gemini 3.8 Live で約$0.023/分）。会話時間がそのまま課金対象になります。
注意: この表は「安さ」の比較であって「良さ」の比較ではありません。音声認識の精度（WER）や声質は各社が自社に有利な条件で主張しており、当サイトが同じ条件で測った数値は持っていません。乗り換え前には自分の音声で同じファイルを流して確かめるのが最短です。
