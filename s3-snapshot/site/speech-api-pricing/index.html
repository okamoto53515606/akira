このページの範囲: 読み上げ（TTS）と文字起こし（STT）の単価を「1分」「1時間」にそろえて並べます。課金単位が4種類（1M文字・1Mトークン・1分・1時間）に分かれているため、そのままでは比べられません。換算の前提は折りたたみに明記しています（各社公式ページを2026-11-15に取得）。

結論（3行）

  • 日本語ナレーション → MAI-Voice-2.1-Flash（$0.0045/分）。OpenAI tts-1 も同額だが Deprecated なので現行では選ばない。
  • 文字起こし（録音ファイル） → MAI-Transcribe-2（$0.10/時間）。年末までの期間限定価格。次点は Meta Muse Voice Transcribe の $0.18/時間。
  • リアルタイム対話 → 分単価が1桁違う（$0.023/分〜）。録音ファイルの処理と同じ表で比べない。

注意（4点）

  • OpenAI の文字課金TTS 3モデル（tts-1 / tts-1-hd / gpt-4o-mini-tts）は Deprecated。比較用に残していますが、新規採用の候補ではありません。
  • 「1分=300文字」は当サイトの前提です（日本語ナレーション想定）。英語は約3倍速いため、文字課金モデルは1分あたりの消費文字数が増えます。
  • Gemini の TTS 2モデルは 2027-01-01 に単価が2倍になります（表の → の右側）。
  • gpt-4o-mini-tts は音声トークンの秒換算が公式に無いため、1分単価は概算です。
換算の前提と、公式の逐語（クリックで開く）
  • 音声トークン: 1秒 = 25トークン（1分 = 1,500） — Google公式の注記
  • 文字→音声の長さ: 1分 = 300文字（5文字/秒） — 当サイトの前提（公式に読み上げ速度の規定は無い）
  • 1,000字 = 3分20秒（200秒）／1時間 = 18,000文字 — 上記からの計算
  • 通貨は USD のみ・為替換算なし
Audio tokens correspond to 25 tokens per second of audio.
