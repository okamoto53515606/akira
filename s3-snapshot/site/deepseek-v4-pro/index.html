DeepSeek V4 Pro は提供継続へ — 9/14 の V4.1 Flash ルーティング予告は撤回

2026-09-10、DeepSeek は新世代の DeepSeek-V4.1-Flash をリリースした際、あわせて V4 Pro を順次 retire し、2026-09-14 以降 deepseek-v4-pro 宛のリクエストを V4.1 Flash へルーティングすると予告していました。 その後 DeepSeek はこの予告を撤回し、現在は「2026-09-14 以降も V4 Pro の API 提供を継続し、課金方法は変更しない」と公式に告知しています。 このページは、V4 Pro を使い続けている人・これから導入する人のために、現行のステータス・料金・仕様と、撤回の経緯、そして V4.1 Flash との使い分けを公式ドキュメントの記述だけで整理したものです。 V4.1 Flash 本体の料金・スペック・ベンチマーク・導入手順は DeepSeek V4.1 Flash 実践ガイドにまとめています。

【重要】当サイトの旧記載の訂正と、公式予告の撤回について

何が撤回されたのか

本ページを含む当サイトの一部ページでは、2026-09-11 時点で 「2026-09-14 13:00 JST（12:00 北京時間 / 04:00 UTC）以降、V4.1 Pro がリリースされるまでの間、deepseek-v4-pro 宛のリクエストは全て V4.1 Flash にルーティングされ、V4.1 Flash の価格で課金される」と掲載していました。 この記述は公式に撤回されました。現在は誤りです。

当時 DeepSeek は、V4.1 Flash が「性能・コスト・速度・総時間のいずれでも V4 Pro を上回る」として V4 Pro を順次 retire すると表明していました。 しかしその後、公式料金ページの注記(2) および Change Log（2026-09-10 エントリ）の両方が、次の文面に差し替えられています（原文）:

"In response to user demand, we have decided to continue providing API services for DeepSeek V4 Pro after September 14, 2026, with the billing method remaining unchanged. We will provide further notice should there be any changes."

つまり 以前に予告されていた退役と 9/14 のルーティングは、2026-09-13 現在の公式記載には存在しません。 本ページの記載は、この撤回を反映した内容に全面的に書き換えました（最終更新 2026-09-13）。 なお V4 Pro を「退役する」と書いた外部のまとめ記事や、9/11 時点で配信された告知を引用した情報が今も見つかりますが、 2026-09-13 時点の公式一次情報は「提供継続」です。古い情報に触れた場合はこの点にご注意ください。

（注）表現について: 公式の文面は "withdrawn"（撤回）と明言しているわけではなく、「ユーザーの要望を受け、2026-09-14 以降も V4 Pro の API サービス提供を継続し、課金方法は変更しない」と告知しています。本ページでは、従来の 9/14 ルーティング予告が現行の公式記載（料金ページ footnote (2)・Change Log）に存在しないことを、当サイトの整理として「撤回」と表現しています。公式は「変更があれば改めて告知する」としているため、今後の動向は公式情報をご確認ください。

よくある質問

Q. 9月14日以降、V4 Pro はどうなりますか？

A. 提供が継続されます。公式は「ユーザーの要望を受け、2026-09-14 以降も DeepSeek V4 Pro の API サービス提供を継続する。課金方法は変更しない。変更があれば改めて告知する」と発表しています。以前に告知されていた「9/14 以降は V4.1 Flash へルーティング」は撤回されました。

Q. 「billing method remaining unchanged」とはどういう意味ですか？

A. V4 Pro は V4.1 Flash の価格に統合されず、V4 Pro 専用の料金体系がそのまま続くという意味です。実際、公式料金ページには現在も V4 Pro の独立した価格行（cache hit $0.022/$0.044、cache miss $0.66/$1.32、出力 $1.98/$3.96）が掲載されています。V4.1 Flash の価格（$0.15/$0.30、$0.003/$0.006、$0.60/$1.20）とは別建てのままです。

Q. コードやAPIキーを書き換える必要はありますか？

A. 不要です。deepseek-v4-pro を指定しているコードはそのまま動き続けます。むしろ今回の撤回により、9/11 時点で「移行のため」に行った変更を戻す必要が出てくる可能性があります。ただし V4.1 Flash の方が単価・速度・画像対応で有利なため、移行自体に価値がある場面は残ります。

Q. V4 Pro の料金はまだ有効ですか？

A. 有効です。cache miss 入力 オフピーク $0.66 / ピーク $1.32、cache hit 入力 $0.022 / $0.044、出力 オフピーク $1.98 / ピーク $3.96（USD・1Mトークンあたり）。以前の「2026-09-13 までの参考値」という記載は誤りだったため訂正しました。

Q. 結局 V4 Pro と V4.1 Flash、どちらを使えばいいですか？

A. 公式は 2026-09-10 の告知で「V4.1 Flash が性能・コスト・速度・総時間で V4 Pro を上回る」としていましたが、その告知文は今回の撤回で差し替えられており、現在の公式ページにこの比較記述はありません。コンテキスト長（1M）と最大出力（384K）は同一なので、判断材料は単価・Vision 対応・同時実行数・推論の深さになります。画像を含む処理や大量バッチは V4.1 Flash、深い推論が効く処理は V4 Pro を実測比較して選ぶのが確実です。

Q. また予告が変わる可能性はありますか？

A. あります。公式は「変更があれば改めて告知する（We will provide further notice should there be any changes）」と明記しています。本サイトは公式料金ページと Change Log を継続的に確認し、変動があればこのページを更新します。

Q. V4 Pro は画像を扱えますか？

A. 扱えません。公式の機能表で V4 Pro の Vision は「Not supported」です。画像入力が必要な場合は V4.1 Flash（ネイティブ対応）を使ってください。画像・音声・動画・PDF の対応状況は マルチモーダル対応LLM一覧を参照してください。
