性能 — 3.6 Flashからコーディング・エージェント性能が大幅向上

Gemini 3.6 Flashをベースにアルゴリズム改善したモデル。コーディング・エージェント・ナレッジワーク全般で向上。

  • FrontierCode 1.1 Main: 43.6% — プロダクションコード品質で3.6 Flash（34.4%）から大幅向上。Claude Sonnet 5（42.7%）やGPT-5.6 Terra（41.3%）も上回る。
  • DeepSWE v1.1: 65.3% — 長期間ソフトウェアエンジニアリングで3.6 Flash（48.6%）から+16.7pt。
  • Code Arena（WebDev）Elo: 1588 — 3.6 Flash（1538）を上回る。
  • Terminal-bench 2.1: 85.8% — エージェント型ターミナルコーディング（3.6 Flashは78.0%）。
  • GDP.pdf: 34.0% — 複雑なドキュメント処理で3.6 Flash（22.0%）を大幅に上回る。
  • AutomationBench: 30.4% — 実務ワークフロー自動化（3.6 Flashは17.0%）。
  • Harvey LAB-AA: 90.7% — 複雑な法律ワークフローでClaude Sonnet 5（90.1%）超え。
  • AA Intelligence Index: 56 — 3.6 Flash（52）から向上（GPT-5.6 Terra/Claude Sonnet 5は55/57帯）。

Googleは3.7 Flashを「エージェントワークフローとマルチモーダル推論のための最も高性能なFlashモデル」と位置づけ、thinking設定で品質・コスト・レイテンシのバランスを制御可能。
