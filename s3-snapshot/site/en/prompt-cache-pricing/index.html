Prompt Caching Pricing Compared [November 2026]

How far does the input rate drop when you reuse the same long prefix (system prompt, document set, codebase) with each vendor's cache? This page is the rate-and-terms comparison; the concept is explained in the glossary entry on prompt caching, and standard (non-cached) rates are in the LLM API pricing comparison.

●Last updated: November 14, 2026 | Every vendor page was fetched on 10 Nov 2026; quotations are verbatim and the ratio/absolute conversions are ours.

Three things to know first

  • Reads are cheap, writes are expensive. Cache reads land at 0.025x to 0.1x of the normal input rate, while writes cost 1.25x to 2x (OpenAI and Anthropic both work this way). Caching a prefix you will only send once costs you more than not caching it.
  • Discounts are quoted against the normal input rate. "90% off" means different money on a $0.10 model than on a $10 model, so the table shows both the multiplier and the absolute rate.
  • Terms differ more than prices do. Some caches are automatic (OpenAI, Moonshot, DeepSeek, Google's implicit caching), while Anthropic makes you place explicit cache breakpoints.

OpenAI write rates are the official multipliers (1.25x for the 30-minute lifetime, 2.5x for 12 hours) applied to normal input; the docs stress that a cache write is not an additive fee but a replacement rate. Anthropic writes are 1.25x (5 min) and 2x (1 hour), reads are 0.1x (0.025x on Fable 5.1 and Mythos 5.1, 0.05x on Opus 5.5 and Sonnet 5.5). DeepSeek shows off-peak / peak.

Write versus read: when caching pays off

OpenAI states the break-even arithmetic verbatim:

"At the 0.1× read rate with 30-minute writes, writing a prefix once and fully reusing it once costs 1.35× its ordinary input cost, compared with 2× for processing it twice without caching."

The same structure holds elsewhere. For Moonshot's kimi-k3.1-pro a 5-minute write ($2.00) equals the normal input rate ($2.00) while reads fall to $0.20. Anthropic charges 1.25x or 2x on writes in exchange for reads down to 0.025x-0.1x. How many times you reuse the prefix is what decides the bill.
