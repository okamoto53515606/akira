Image & Video Generation API Pricing [Nov 2026]

Scope of this page: image and video generation rates, placed on a common per-image and per-second basis. Billing units come in three shapes (per image, per 1M tokens, per second), which cannot be compared as published. Every per-image figure below is the provider's own published conversion; we do not estimate token counts ourselves (all provider pages retrieved 2026-11-15).

●Last updated: 2026-11-15 | Provider pages retrieved 2026-11-15. Google publishes per-image equivalents; Microsoft and OpenAI publish only per-token rates, so cells we cannot confirm are marked "not published".

Bottom line (3 points)

  • Among token-billed models, only Google publishes per-image conversions (Meta publishes a flat per-image price). Nano Banana 2.1 is $0.0336 per 1K image (1024x1024px); Nano Banana Pro is $0.134 at 1K/2K. Meta's Muse Image is a flat $0.01 per image — the cheapest published figure here (quality is a separate question).
  • Microsoft's MAI-Image output rates run from $19 to $106 per 1M tokens — a 5x spread. Tokens per image are not published, so the per-image cost stays unknown until you run Microsoft's own calculator.
  • Video belongs in its own table. Gemini Omni 1.2 Flash works out at about $0.07 per second at 720p (about $0.70 for a 10s clip) per Google's own conversion. OpenAI's pricing page lists no video generation rates, and no "Veo"-named model appears on Google's current pricing page, so both stay unconfirmed.

Putting "$30 per 1M tokens" next to "$0.01 per image" tells you nothing until you know how many tokens one image consumes.
  • Images are billed as output tokens (Google, Microsoft, OpenAI). Token counts move with resolution and quality, so the same $30 per 1M yields different per-image costs. Google publishes the counts: 1,120 tokens at 1K and 3,780 at 4K for Nano Banana 2.1.
  • Meta alone uses a flat per-image price ($0.01). Easy to read, but the table does not reveal how quality or resolution change the bill.
  • Video is output tokens multiplied by seconds — effectively per-second billing, which is why Google states a per-second equivalent in its notes.
  • Inputs are priced separately. For editing workflows that re-send a reference image, input can dominate (Nano Banana Pro counts an input image as 560 tokens = $0.0011).

Caveats (4)

  • The MAI-Image-2.6 / 2.6-Flash rates exist only in a blog post. The Azure "Foundry Models pricing" table still lists five rows (MAI-Image-2 / 2-Efficient / 2.5 / 2.5 Flash / 2.5 Pro) with no 2.6 entry. Confirm on the Foundry pricing page before you commit.
  • Google's per-image price varies more than 3x with resolution (Nano Banana 2.1: $0.0336 at 1K vs $0.113 at 4K). Budget at "$0.03 per image" and a 4K pipeline bills roughly triple.
  • GPT-Image-2.6 needs the official calculator. Only $30 per 1M image output tokens is published; the fixed tokens-per-image table on the docs site covers models before gpt-image-2.
  • Batch is roughly half price (Google $15 per 1M, OpenAI $15 per 1M). If latency is not critical, budget on Batch.
