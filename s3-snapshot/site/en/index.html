Moonshot AI's flagship (kimi-k3.1-pro): $2.00 input, $10.00 output and $0.20 cached input per 1M tokens, about 33% below the previous Kimi K3 ($3/$15). 1,048,576-token context, cache billing on by default (5-minute and 1-hour write tiers), Batch at 60% of standard. Released 2026-09-22. $4 input / $20 output / $0.20 cache read (down from Opus 5's $5/$25). 1M context, 128K output. All nine official benchmarks with the harness owner noted, the basis for the 40%-cheaper claim, and the change that thinking can no longer be turned off.

Claude Sonnet 5.5 — the balanced model of the Claude 5.5 family

Released 2026-09-28 at $2 input / $10 output, the same as the previous-generation Sonnet 5, and $0.10 cache reads — half of Sonnet 5's $0.20 (the docs call it "0.05x on Claude Opus 5.5 and Claude Sonnet 5.5"). 1M context, 128K max output, adaptive thinking on by default with a default effort of high and a between_tools setting that turns up-front thinking off. No official benchmarks are published, so we publish none: only verified specs and the model ID on each of the five platforms.
