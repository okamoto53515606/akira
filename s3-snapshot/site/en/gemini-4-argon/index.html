The short version — six things that matter

  • $2.00 input, $10.00 output and $0.10 caching are introductory prices. The pricing cells read “$2.00 through November 30, 2026. $4.00 starting December 1, 2026.” On December 1, 2026 all three double.
  • No free tier. Verbatim: “Free Tier: Not available”.
  • Implicit caching only. Verbatim: “Implicit caching only (explicit caching is not supported)”. You cannot create or manage caches explicitly.
  • The context window is a unified input+output limit of 1,048,576 tokens. Verbatim: “Context window (unified input and output token limit) 1,048,576”.
  • Output pricing includes thinking tokens. Verbatim: “Output price (including thinking tokens)”. Heavy thinking raises the billed output side.
  • No day-level release date is published. The only date signal is “Latest update: October 2026” on the model page, so we write “October 2026” instead of inventing a day.

What it is positioned for (official wording)

“Gemini 4 Argon (gemini-4-argon) is our flagship reasoning model, built for complex software engineering, deep mathematical and scientific problem solving, autonomous multi-step agents, and long decode up to 1M tokens.” — Gemini API “Gemini 4 Argon” (checked 2026-10-21)

Our reading: it targets (1) writing and fixing code, (2) hard maths and science, (3) agents that call tools repeatedly, and (4) very long generations. We found no benchmark table on the official model or pricing page, so we publish no numbers — see how to read benchmarks for why third-party harness numbers need a label.

Caveats and what we could not confirm

  • December 1 pricing is a forecast. It comes from “starting December 1, 2026” in the official price cells and does not apply before that date. We keep intro and forecast prices in separate columns.
  • Explicit caching is not supported, so you cannot control cache creation or eviction.
  • No free tier — a paid API key is required to try it.
  • Unconfirmed: Batch / Priority rates, any long-context surcharge, official benchmark numbers, and a day-level release date. We do not invent values or dates.
