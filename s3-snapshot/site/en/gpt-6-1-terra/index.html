GPT-6.1 Terra

OpenAI's fast, low-cost computer-use model announced on October 26, 2026. It is the step up from GPT-5.6 Terra, and its standard API prices are 50% lower than GPT-5.6 Terra and GPT-6.1 Sol.

●Last updated: October 29, 2026 | Primary sources: OpenAI launch post · official model page · official pricing

In short

  • $1.00 input, $0.05 cached input, $5.00 output per 1M tokens (official model page). Cached input is 5% of the input rate.
  • The predecessor is GPT-5.6 Terra, not GPT-6.1 Sol. OpenAI's verbatim: "A significant step up from GPT-5.6 Terra". Sol is a separate, higher grade in the same GPT-6.1 generation.
  • 1,050,000-token context and 128,000 max output tokens. Knowledge cutoff 2026-06-01 (official model page).
  • Above 272,000 input tokens the whole request is repriced at 2x input and 1.5x output. Streaming one huge document is expensive.
  • Reasoning effort: none / low / medium (default) / high / xhigh / max. Input: text and image. Output: text.
  • Available in ChatGPT Work and Codex (Plus, Pro, Enterprise, Edu) and in the API as gpt-6.1-terra.
  • The launch post gives no explicit date ("Starting today"); third-party coverage agrees on October 26, 2026, and we label it as such.

The 272K wall: one giant request costs double

Official wording: "Prompts with more than 272K input tokens are priced at 2x input and cache rates and 1.5x output for the full request." A 1.05M window does not mean a 1.05M request is cheap.

CaseMathCost
300,000 input + 5,000 output in one request$2/M x 0.3 + $7.5/M x 0.005
(2x input, 1.5x output because the request exceeds 272K)		~$0.64
Same content split into three 100,000-token calls$1/M x 0.3 + $5/M x 0.005
(under 272K, so no multiplier; 5,000 output tokens split across the calls)		~$0.33
  • Context size and request size are different things. Crossing 272K reprices the entire request.
  • Long conversations benefit from $0.05 cached input — until the request passes 272K, when cache rates double to $0.10/M.
  • All figures are arithmetic from official multipliers; check actual billing in API responses.

Availability

  • ChatGPT Work and Codex: available to all Plus, Pro, Enterprise and Edu users (official wording).
  • API: model ID gpt-6.1-terra (official post and model page).
  • Stage: general availability. The post lists no waitlist, preview or research-preview label.
  • Third-party: GitHub's changelog announced GPT-6.1 Terra as generally available in GitHub Copilot on 2026-10-26 (treated here as third-party information).

Source: OpenAI — Pricing and availability (retrieved 2026-10-29)

Where it fits, and what to watch

  • Built for high-volume work: invoice reading and data entry, form filling, video editing — the everyday tasks the launch post names.
  • Not the pick for the hardest coding: OpenAI itself says Sol and Astra "remain the better choice" there.
  • Safety: OpenAI states Terra meets the "Critical" cybersecurity threshold under its Preparedness Framework; see the system card.
  • Prices and specs change; always re-check the official page before committing.
