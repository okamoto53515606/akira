Bottom line

  • Output rates run from ¥43 to ¥3,100 per 1M tokens: Claude Opus 5.5 ¥3,100, MiMo-V2.6-Flash ¥43 — about a 71x spread.
  • Input and output are priced separately, output at about 5x input on most models (GPT-6.1 Sol: ¥310 in, ¥1,550 out).
  • DeepSeek is the only two-tier one. Off-peak is half of peak; the table shows both.

The yen column is the USD rate times 155. Rounding: one decimal below ¥10, otherwise nearest yen. Rates move daily, so treat this as a reference, not a quote.
  • Per what: everything is per 1M tokens. 100,000 tokens is a tenth of the table.
  • Not included: consumption tax, card fees, FX spread. These are not your invoice amount.
  • Priced separately: cached input, Batch, long-context tiers (above 272K tokens), priority. This table is standard input and output only.

Three caveats

  • ¥155 = $1 is fixed — set as the site’s conversion basis on 15 Nov 2026; we do not track the live rate. The table does not move with the market; billing is in USD, so your yen cost follows the charge-day rate.
  • We do not move the page date for FX moves. It changes only when a provider changes its USD rate.
  • Your bill depends on token counts. The token calculator shows the cost in both currencies.
