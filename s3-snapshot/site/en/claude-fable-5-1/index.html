Fable 5.1 vs Mythos 5.1

Same model, different safeguards. The two share the same underlying model; only the strength of applied safeguards differs.

Claude Fable 5.1 — generally available to all users via the API, Claude.ai, Claude Code and Claude Cowork.
Claude Mythos 5.1 — trusted-access only. A version with relaxed safeguards in cybersecurity (CVP) and life sciences (LSVP) for vetted organizations. See the Mythos 5.1 page for details.
