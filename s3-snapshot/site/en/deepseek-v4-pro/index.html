DeepSeek V4 Pro Stays Available — the 9/14 V4.1 Flash Routing Notice Is Withdrawn

When DeepSeek released DeepSeek-V4.1-Flash on 2026-09-10, it also announced that it would retire V4 Pro in an orderly manner and route all deepseek-v4-pro requests to V4.1 Flash from 2026-09-14. DeepSeek has since reversed that notice. The company now states that it will continue serving the V4 Pro API after 2026-09-14 with the billing method unchanged. This page documents the current status, pricing and specifications, the history of the reversal, and how to choose between V4 Pro and V4.1 Flash, using only DeepSeek's own official documentation. For the full V4.1 Flash guide (pricing, specs, benchmarks, setup), see the DeepSeek V4.1 Flash guide.

● Last updated: September 13, 2026  |  Primary sources: official pricing page · Change Log  |  Retrieved: 2026-09-13

✅ Bottom line (3 points)

  • deepseek-v4-pro keeps working after 2026-09-14. DeepSeek states: "In response to user demand, we have decided to continue providing API services for DeepSeek V4 Pro after September 14, 2026, with the billing method remaining unchanged."
  • V4 Pro keeps its own separate rate card. The official pricing page still lists a dedicated V4 Pro row — it was not consolidated into V4.1 Flash pricing (off-peak input $0.66 / output $1.98).
  • The "everything routes to V4.1 Flash at the Flash price from 13:00 JST on 2026-09-14" notice has been withdrawn. DeepSeek nonetheless says it "will provide further notice should there be any changes," so future changes are not impossible.

→ For the cheaper, vision-capable sibling, see the DeepSeek V4.1 Flash guide.

【Important】Correction to our earlier coverage, and what DeepSeek withdrew

What was withdrawn

Until 2026-09-11, this page (and other pages on this site) stated that "from 13:00 JST on 2026-09-14 (12:00 Beijing time / 04:00 UTC), and until V4.1 Pro is released, all requests to deepseek-v4-pro are routed to V4.1 Flash and billed at the V4.1 Flash price." That statement has been withdrawn by DeepSeek and is no longer correct.

At the time, DeepSeek said V4.1 Flash "has comprehensively surpassed V4 Pro in performance, cost, speed, and total time, so we plan to retire V4 Pro in an orderly manner." Since then, both footnote (2) of the official pricing page and the Change Log (2026-09-10 entry) have been replaced with the following (verbatim):

"In response to user demand, we have decided to continue providing API services for DeepSeek V4 Pro after September 14, 2026, with the billing method remaining unchanged. We will provide further notice should there be any changes."

In other words, as of 2026-09-13 there is no retirement schedule and no 9/14 routing in the official documentation. We have rewritten this page to reflect the reversal (last updated 2026-09-13). Note that third-party round-ups still describe V4 Pro as retiring, and the 9/11 notice is still quoted in places — as of 2026-09-13 the official primary source says V4 Pro continues.

Note on wording: DeepSeek does not itself use the word "withdrawn". The official text now states that, in response to user demand, API services for DeepSeek V4 Pro will continue after September 14, 2026 with the billing method unchanged. We describe the earlier routing notice as withdrawn because it is no longer present in the current official documentation (pricing-page footnote (2) and the Change Log). DeepSeek says it will provide further notice of any changes, so check the official pages for the latest status.

FAQ

Q. What happens to V4 Pro after September 14?

A. It keeps running. DeepSeek states that, in response to user demand, it will continue providing API services for DeepSeek V4 Pro after September 14, 2026, with billing unchanged, and will give further notice if anything changes. The previously announced "routes to V4.1 Flash from 9/14" plan was withdrawn.

Q. What does "billing method remaining unchanged" actually mean?

A. It means V4 Pro was not folded into V4.1 Flash pricing — V4 Pro's own rate structure continues. The official pricing page still carries a dedicated V4 Pro row (cache hit $0.022/$0.044, cache miss $0.66/$1.32, output $1.98/$3.96), separate from the V4.1 Flash rates ($0.15/$0.30, $0.003/$0.006, $0.60/$1.20).

Q. Do I need to change my code or API key?

A. No. Code that specifies deepseek-v4-pro keeps working. In fact, because of the reversal, any migration you performed on the assumption of the 9/11 notice may now be unnecessary. Moving to V4.1 Flash can still make sense on price, speed and vision support.

Q. Is V4 Pro pricing still valid?

A. Yes. Cache-miss input $0.66 off-peak / $1.32 peak, cache-hit input $0.022 / $0.044, output $1.98 off-peak / $3.96 peak, in USD per 1M tokens. Our previous "reference values valid only through 2026-09-13" wording was wrong and has been corrected.

Q. So which should I use — V4 Pro or V4.1 Flash?

A. DeepSeek's 2026-09-10 announcement claimed V4.1 Flash beats V4 Pro on performance, cost, speed and total time, but that text was part of the notice that has now been replaced, and the current official pages no longer carry the comparison. Context (1M) and max output (384K) are identical, so the decision rests on price, vision support, concurrency and reasoning depth. Use V4.1 Flash for image-bearing or high-volume work; benchmark V4 Pro where deeper reasoning pays off.

Q. Could the notice change again?

A. Yes. DeepSeek explicitly says it "will provide further notice should there be any changes." We keep checking the official pricing page and Change Log and will update this page if anything moves.

Q. Does V4 Pro support images?

A. No. The official feature table marks Vision as "Not supported" for V4 Pro. Use V4.1 Flash for image input. See the multimodal LLM guide for image, audio, video and PDF support across providers.
