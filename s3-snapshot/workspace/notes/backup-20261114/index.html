先に押さえる3点

  • キャッシュ読込の「割引率」は5モデルで4倍の開きがある。最も深いのは Claude Fable 5.2 の0.025×（97.5%減）、中間が Muse Wonder の0.05×（95%減）、最も浅いのが GPT-6 Astra と Kimi K3.1 Pro の0.1×（90%減）。同じ前置きを毎回送る workload では、入力単価の安さより読込倍率のほうが効くことがあります。
  • 割引率と実額は別物。読込単価の絶対額は GPT-6 Astra の $1.00 が最も高く、Fable 5.2 と Kimi K3.1 Pro と Muse Wonder が $0.20 で並びます。率で選ぶと判断を誤ります。
  • ZDR（保存しない）を選ぶと機能が落ちる。Meta は公式ヘルプで「ZDR有効時はサーバー側の会話状態・非同期リクエスト・ファイルアップロード・Web検索・Contributor modeが使えない」と明記しています。保持を削る設定は、機能を削る設定と同じです。
