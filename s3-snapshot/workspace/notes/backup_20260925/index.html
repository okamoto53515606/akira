なぜ「中国系AI」を追うのか

オープンウェイト戦略と低価格で、API・ローカル実行の両面で存在感を高めています。

  • 「DeepSeekショック」の起点 — DeepSeek R1（2025-01）がo1級の推論を低コスト・MITライセンスで公開し、業界の価格・公開戦略を一変させた。
  • オープンウェイトの主戦場 — Qwen・GLM・Kimi・MiniMax・DeepSeekが相次いでフラッグシップ級を公開。MIT/Apache 2.0系ライセンスで商用利用しやすいモデルが多い。
  • 価格競争力 — DeepSeekのピーク/オフピーク制や、Qwen/GLMの低価格フラッグシップにより、同性能帯で西側モデルの数分の一〜数十分の一のコストになるケースも。
  • 注意点 — ベンチマークの自己公表値と独立評価には差が出る場合がある。データ主権・リージョン規制・利用規約も併せて確認が必要。

主要ラボとフラッグシップ

DeepSeek

DeepSeek（深度求索）

R1で「DeepSeekショック」を起こした中国発の代表格。2026-09-10リリースの V4.1 Flash が現行（1Mコンテキスト・384K出力・ネイティブ画像入力）。V4 Flash / Vision Exp は V4.1 Flash へ統合。V4 Pro は 9/14 以降も提供継続（9/14 ルーティング予告は撤回）。MITライセンス。2026-08-16よりピーク/オフピーク価格制。実践ガイド・V4 Proの経緯・料金。

Qwen / Alibaba

Qwen（通義千問 / 阿里云）

Alibabaのオープンウェイト・モデルファミリー。フラッグシップ Qwen3.8-Max（2026-08-03 GA）は2.4TパラメータMoE・1Mコンテキスト。低コストの Qwen3.8-Flash（2026-08-26）は125B/6B active MoEでQwen4アーキテクチャのプレビュー（オープンウェイト版Flash-NextはHF/ModelScopeで公開。ライセンス条件は各モデルカードで要確認）。Qwen3.8-Flash詳細。

GLM / Zhipu

GLM（智譜AI / Z.ai）

清華大学発のラボ。GLM-5.2（2026-06-16）は744B MoE・MITライセンス、GLM-5.3（2026-08-14）は同価格で公開。GLM-5.3-Flash（2026-08-26）は320B/18B MoEのネイティブマルチモーダルで、list $0.15/$0.50。世界初の基盤モデルAI上場企業（2026-01、香港）。GLM 5.3 Flash詳細。

Kimi / Moonshot

Kimi（Moonshot AI / 月之暗面）

北京のスタートアップ。Kimi K3（2026-07-16）は2.8Tパラメータ・ネイティブvision・1Mコンテキストで、API料金は入力$3.00／出力$15.00（キャッシュヒット入力$0.30。いずれもMoonshot直販の価格）。低価格路線ではなくClaude Sonnet級の価格帯です。OpenRouter等の第三者ホスト経由でも提供され、2026-09にAmazon Bedrockでも利用可能になりました（AWS公式ブログ 2026-09-18）。K2.6（2026-04）はSWE-bench ProでGPT-5.5と同等と報告。

MiniMax

MiniMax

M3（2026-05/06）はマルチモーダルMoE・1Mコンテキスト。M2.7は2026-04-12にオープンソース化。低価格のエージェント向けモデルが主力。

StepFun / 階躍星辰

StepFun（階躍星辰）

中国のAIスタートアップ。公式ドキュメントの料金表に「マルチモーダル推論モデル（Multimodal Reasoning Models）」という区分があり、2026-09-23時点で step-5-preview（$1.00 / $2.70）と step-3.7-flash（$0.20 / $1.15）が掲載されています（キャッシュ入力はそれぞれ$0.05 / $0.04）。テキスト専用・音声・画像生成まで含む幅広い体系で、音声系は stepaudio-2.5-realtime（$1.50/$10.00）や step-audio-r1.5（$1.43/$15.00）などをラインアップ。料金の内訳。

その他

ByteDance Doubao / Baidu ERNIE / Tencent Hunyuan

ByteDanceのDoubao（豆包）は消費者向けで国内最大級のユーザー規模（クローズド）。BaiduのERNIE 5.xはオムニモーダル（ERNIE 4.5のみオープンソース）。TencentはHunyuan-A13Bをオープン公開。
